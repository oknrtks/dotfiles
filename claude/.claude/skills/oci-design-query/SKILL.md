# OCI設計書効率的問い合わせシステム

OCI設計書Excelファイルを効率的に分析・問い合わせするためのシステム設計と実装ガイドです。

## 概要

OCI設計書は固定フォーマット（ファイル名規則、シート構造、マルチヘッダ）で複数テナント分存在します。毎回Excelを解析するのは非効率なため、以下の最適化を行います。

- **パース済DataFrameキャッシュ**: XMLパースコストを一度だけ支払う
- **インデックス（ポインタのみ）**: 「どこにあるか」を高速に特定
- **タイムスタンプ監視**: 更新されたファイルのみ差分更新
- **遅延ロード**: 必要なテナントのみメモリに載せる

## 主な機能

- **行単位取得**: 特定リソースの全属性値を高速取得（O(1)）
- **列単位取得**: ある列の全設定値リストを高速取得（O(1)）
- **テナント横断検索**: 複数テナントから並列検索（O(テナント数)）
- **自動更新検知**: ファイル更新時、差分のみ再ロード
- **メモリ効率**: 遅延ロードで必要なテナントのみメモリに載せる

## 性能目標

- 初回ロード（1テナント）: <3秒
- 行単位取得: <10ms
- 列単位取得: <10ms
- 横断検索（10テナント）: <100ms
- メモリ使用（1テナント）: <50MB

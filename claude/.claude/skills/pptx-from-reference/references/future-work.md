# R5: 外部画像 API 連携 (将来計画)

v1.0 ではスコープ外。将来バージョンで実装予定。

## 概要

ネイティブ shape では困難な概念図に限り、外部画像生成 API でイラストを挿入する機能。

## v1.0 での暫定対応

- `slide_plan.json` で `image_placeholder` が指定された箇所には、灰色矩形 + ラベルの shape プレースホルダを配置
- ユーザに「この箇所は手動で画像を差し替えてください」と案内

## 将来の実装方針

- 画像生成 API (DALL-E, Stable Diffusion 等) との連携
- slide_plan の `image_placeholder.prompt` フィールドから画像生成
- 生成画像を PPTX に自動挿入
- 解像度・アスペクト比の自動調整

## 検討事項

- API コスト管理
- 画像スタイルの参照資料との整合性
- 生成画像のライセンス
- オフライン環境でのフォールバック

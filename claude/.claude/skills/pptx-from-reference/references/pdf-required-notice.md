# PDF ファイルが見つかりません

参照用の `.pptx` ファイルは確認できましたが、同名の `.pdf` ファイルが見つかりませんでした。

このスキルでは、参照資料のレイアウトや文体を正確に継承するために、`.pptx` と同名の `.pdf` の両方が必要です。

## 対応方法

1. 参照用の `.pptx` ファイルを PowerPoint で開く
2. 「ファイル」→「名前を付けて保存」→ ファイル形式で「PDF」を選択
3. `.pptx` と同じファイル名(拡張子のみ異なる)で保存する

例:
- `reference.pptx` → `reference.pdf`
- `template.pptx` → `template.pdf`

PDF を用意できましたら、再度お試しください。

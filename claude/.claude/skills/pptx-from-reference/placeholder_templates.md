# Placeholderテンプレート集

このファイルに定義されたフォーマットを必ず使用すること。
独自のフォーマットを作成してはならない。

## 使用手順
1. Readツールでこのファイルを開く
2. 該当するテンプレート（本文/リード文/タイトル等）をコピー
3. `#XXXXXX` `XXpt` 等のプレースホルダーを元スライドの実際の値に置換
4. 必要に応じて項目を追加・削除（構造は維持）

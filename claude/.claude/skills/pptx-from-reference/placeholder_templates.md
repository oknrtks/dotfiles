# Placeholderテンプレート集

このファイルに定義されたフォーマットを必ず使用すること。
独自のフォーマットを作成してはならない。

## 使用手順
1. Readツールでこのファイルを開く
2. 該当するテンプレート（本文/リード文/タイトル等）をコピー
3. `#XXXXXX` `XXpt` 等のプレースホルダーを元スライドの実際の値に置換
4. 必要に応じて項目を追加・削除（構造は維持）

---

## 本文（汎用）
【本文】詳細説明・根拠・データなどを記載
・文字色: #XXXXXX / サイズ: XXpt
・強調方法: 色(#XXXXXX) / Bold / Italic / フォント拡大
・文体: ですます調 / 箇条書き多用 等
・構成: 1ペイン / 2ペイン(左:図 右:説明) 等
・図: あり（中央に概念図を配置するスタイル） / なし
・表: あり / なし

## 表（ヘッダー行あり）- データセル内詳細情報付き

表の構造はそのまま保持し、各セルに以下のPlaceholderを設定：

**ヘッダー行（1行目）:**
- 【ヘッダー1】【ヘッダー2】...

**データ行 最初のセル（詳細情報を含む、9ptフォントで記載）:**
```
【データ】この表にデータを入力する
・行数: N行 / 列数: M列
・ヘッダー行: あり
・データ行書式: 文字色: #XXXXXX / サイズ: XXpt
・セル背景: 交互色(#XXXXXX, #XXXXXX) / 単色 / なし
・文体: ですます調 / 体言止め / 簡潔表記
・特記: 元スライドではXXX表（日程表・進捗表等）が使用されていた
```

**データ行 その他のセル:**
- 【データ】

---

**注意:** `convert_table_to_placeholder_with_details()` 関数を使用する場合、以下の形式でtable_info辞書を渡す:

```python
table_info = {
    'color': '#000000',  # データ行の文字色
    'size': '10.5',      # データ行のフォントサイズ（pt）
    'background': '交互色（薄青・薄紫）',  # セル背景の説明
    'style': 'ですます調 / 体言止め',     # 文体
    'note': '元スライドでは進捗表が使用されていた'  # 特記事項
}
```

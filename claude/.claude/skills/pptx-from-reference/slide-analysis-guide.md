# スライド分析ガイド — layout_memo.md フォーマット

Phase 2 の分析メモ（`_work/layout_memo.md`）に記録する内容の詳細フォーマット。

## ファイル先頭（参照資料の概要）

```markdown
# レイアウト分析メモ

- 参照ファイル: <input.pptx>
- 分析日時: YYYY-MM-DD HH:MM
- 総スライド数: N
- 選定スライド: N, N, N（+ 表紙/中表紙/背表紙: N）
```

---

## 各スライドの記録フォーマット

```markdown
## スライドN（元ファイル N 枚目）

### 分類
- 種別: 通常コンテンツ / 表紙 / 中表紙 / 背表紙 / その他
- テンプレート連番: テンプレートスライドN

### 再利用可能と判断した理由
（汎用性・要素の充実度・他スライドとの差別化ポイント）

---

### 要素マッピング（視覚的照合 + コード確認）

> shape_idと視覚画像を必ず照合すること。
> タイトルがPPTXプレースホルダーでなくテキストボックスの場合がある。

| 役割 | shape_id | shape_name | 視覚的位置・特徴 | is_placeholder |
|------|----------|-----------|----------------|---------------|
| タイトル | ... | ... | 左上・大見出し等 | True/False |
| リード文 | ... | ... | 濃紺帯・サブタイトルバー等 | True/False |
| 本文 | ... | ... | 中央本文エリア等 | True/False |
| （サブ要素） | ... | ... | ... | ... |

---

### リード文の文字スタイル
- フォント: XX
- サイズ: XXpt
- 文字色: #XXXXXX
- 背景: 濃紺帯(#XXXXXX) / 白背景 / その他
- 強調方法: Bold / Italic / 色変更(#XXXXXX) / フォント拡大 / なし
- 箇条書き: あり / なし
- 特記: 白文字+濃色背景帯、など

### 本文の文字スタイル
- フォント: XX
- サイズ: XXpt
- 文字色: #XXXXXX
- 強調文字色: #XXXXXX
- 強調方法: Bold / Italic / 色変更 / フォント拡大 / なし
- 箇条書き: あり / なし
- リード文との相違: あり（上記参照） / リード文に同じ

> 「リード文に同じ」は同一が確認できた場合のみ記載。
> 不明な場合はデフォルトで別項目として記録する。

---

### スライド構造
- ペイン構成: 1ペイン / 2ペイン（左:図 右:説明等） / 3ペイン / その他
- サブ構造: あり（サブタイトル・サブリード文・末尾強調ボックス等） / なし
  - サブ構造の詳細: ...
- 図・画像: あり（位置: 左/中/右, 概ねのサイズ: W×H相当） / なし
- 表: あり / なし
  - **表がある場合の詳細記録:**
    - shape_id: XXX
    - 行数: N行 / 列数: M列
    - ヘッダー行: あり（1行目、書式: Bold / 背景色: #XXXXXX） / なし
    - データ行書式: 文字色: #XXXXXX / サイズ: XXpt
    - セル背景: 交互色 / 単色 / なし
    - 内容の性質: 日程表 / 進捗表 / 比較表 / データ表 / その他
    - 処理方針: 構造保持+Placeholder化 / 削除→代替矩形
      - 削除する場合の理由: 複雑な結合セル / 装飾的 / その他
- グラフ: あり / なし

---

### 著者の文体・スタイル
- 文体: ですます調 / である調 / 体言止め多用 / 混在
- 箇条書き: 多用 / ときどき / なし
- 特徴的な文（原文のまま保持）:
  > ...
  > ...
```
